# Francisco

Mi espacio de trabajo con Claude para proyectos de dropshipping. Todo lo que hago en el Mac o en el teléfono se guarda aquí, en GitHub.

## Cómo funciona

- Cuando empiezo a trabajar, Claude trae lo último de GitHub.
- Cuando Claude termina una tarea, guarda los cambios y los sube a GitHub.
- La rama `main` es la versión compartida entre el Mac y el teléfono.
